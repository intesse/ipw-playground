# IPW Playground

Интерактив к докладу «IPW в A/B-тестах».

**Ноутбук (актуальный):** https://colab.research.google.com/drive/1CKbiX8vPp1Hcgk9YrmFN_yx4Z7GuPRWL

## Быстрый старт

Откройте `ipw_playground.html` в браузере или загрузите на Google Диск и раздайте ссылку.

Defaults совпадают с ноутбуком/слайдами:
`confounding=1`, `ATE=+8 п.п.`, `n=100000`, `seed=42`, `trim=0`.

## Сверка цифр (ноутбук ↔ слайды)

| Метрика | Ноутбук | Слайды |
|---|---|---|
| Активные включают | 47% vs 11% (×4.1) | 47% vs 11% (×4) |
| Naive | +18.8 п.п. | +18.8 |
| IPW Hajek | +8.21 [7.38; 9.03] | +8.2 [7.4–9.0] |
| Истина | +8.0 | +8.0 |
| Завышение | ×2.36 (~58% смещения) | ×2.4 (~60%) |
| SMD sessions | 1.083 → 0.009 | 1.08 → 0.009 |

Playground использует тот же DGP (sessions/tenure/ios/prev_purchases, binary conversion).
Из‑за другого ГПС в JS цифры будут *очень близки*, но не бит-в-бит как в NumPy.
